# Exp-12 料理単位の観点（温度・調理法）を加える

## 問い
- 温度・調理法は料理の性質で、食材からは決まらない。料理単位の層を加えると、食材だけから作った空間の見え方はどう変わるか

## データ
- 料理名と手順の文章があるデータ（RecipeNLG など）。利用条件を確認して `data/SOURCES.md` に記録
- 温度（温かい／常温／冷たい）と調理法（焼く・煮る・揚げる・蒸す・生・発酵 など）は手順から LLM で下書きし、抜き取りで本人確認

## 注意
- What's Cooking には料理名も手順もないので、この実験から料理単位のデータに移る。Exp-05（点の粒度）と合わせて設計する

## 2026-10-22 夜: 油分の層（CLA-130）（Claude の記録。計算する前に書いた）

**名前の食い違い**: Linear の CLA-130 の題は「Exp-12 油分の層」だが、この plan.md の Exp-12 は「料理単位の観点（温度・調理法）」。油分の客観値は Exp-11 で作った（`data/labels/fat_content.csv`）。今夜は札の題に従って油分の層をここで比べる（温度・調理法の計画は上のまま残す）。どちらの番号にするかは本人と決める。

### 問い
油分（脂質量）の層は、共起・味・香りの層とどれだけ重なり、どれだけ独立か（Exp-10 と同じ比べ方）。

### やり方（Exp-10 と同じ）
- 対象: 303 食材のうち、脂質量があり（`fat_content.csv` の match が 対応なし 以外）、味が全軸 0 でなく、香りに対応できる食材のペア
- 油分の近さ（先に決めた 2 通り）: (a) −|脂質量の差|（g/100g）、(b) −|log10(脂質量＋1) の差|（脂質量は 0〜100 で偏りが大きいので対数でも見る）
- ほかの層の近さは Exp-10 の定義のまま（共起 word2vec cos・補い合う PPMI・代わりに使える sub・味 cos・香り cos）
- 順位相関（Spearman）を、全ペア・同じ canonical を除く・さらに香りの対応先が同じペアも除く、の 3 つの集合で出す
- 主観値（脂っこさ・コク）は本人の採点が要るのでここでは扱わない

### 結果（2026-10-22、実行後に書いた。Claude の記録）
表は `results/fat_layer.md`（fat_layer.py が生成）。

- **油分（脂質量）の近さは、共起・味・香りのどの層ともほとんど重ならない**（香りの対応先が同じペアも除いた集合で ρ = −0.08〜+0.14）。味×香り（+0.22）より弱い
- 一番大きいのは「代わりに使える（sub）」との +0.14（対数で +0.11）。油どうし・乳製品どうしのように、置き換えて使う食材は脂質量も近い、という向き
- 味（6 軸）とは 0 に近い（−0.02〜+0.02）。Exp-11 の Q10（脂質量と味の各軸の順位相関 |ρ| ≤ 0.20）と合う
- 香りとはわずかに負（−0.08）
- 脂質量が同じ（0 や 0.3）で共起では遠い組み合わせ（砂糖と酢など）が上位に並ぶ。脂質量が 0 の食材が多く、油分の近さには同順位が多い（−|差| の近さが 0 になるペアがたくさんある）
- 主観値（脂っこさ・コク）は本人の採点が要るので、今回は客観値だけ
