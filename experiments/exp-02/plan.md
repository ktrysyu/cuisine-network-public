# Exp-02 味覚スコアと学習空間を比べる

問い: Q4。Exp-01/01b で「醤油↔バター」が地域の軸になり、文化の方向を取り除いても役割（味）は出てこなかった。味の情報を外から与えて、空間のどこに味が入っているかを確かめる。

## 手順（詳細は着手時に詰める）
1. よく使われる食材（~300個）に甘・塩・酸・苦・旨・辛の6軸スコアを付ける。LLM の下書きを本人が直す
   - 味覚スコアは空間の座標には使わない。点に貼る情報として持つ（motivation.md §4）
2. スコアの近さと空間での近さを比べ、一致する例・ずれる例を並べる
3. **PCA 上位成分と味覚の対応**（2026-09-27 追加）
   - 料理ベクトル（または食材ベクトル）の PCA 第1〜第10成分それぞれと、6つの味覚スコアの相関を取る
   - 同じ成分と国籍（one-hot）の対応も取り、「味の成分」か「地域の成分」かを並べて判定する
   - 見たいこと: 第1成分（図2でおかず↔菓子に見えた）が「甘」と強く相関するか。上位成分が地域としか対応しないなら「一番ばらつく向き ≠ 人間が味を判断しやすい向き」
4. 味覚スコアから空間内の「味の方向」を回帰で求め、足し引き（mirin − japanese + french など）をその方向を残す形で試す
