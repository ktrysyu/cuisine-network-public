# Exp-02 味覚スコアの尺度

`data/labels/taste_scores_draft.csv`（Claude の下書き）と、本人が直す `taste_scores.csv` の共通の定義。

## 何を採点するか
- **その食材を単体で、料理に使う通常の形で口にしたときの味**
  - 生で使うのが普通のもの（レモン汁、レタス、薬味のねぎ）は生
  - 加熱して使うのが普通のもの（玉ねぎ、肉、米、パスタ）は**加熱後**。ゆで湯の塩など他の材料の味は含めない
  - 粉・調味料はそのまま（小麦粉はほぼ 0、砂糖は甘 5）
  - 煮出して取り出すもの（ローリエ、シナモンスティック）は煮出した液の味で見る
- 市販品が普通のもの（ブイヨン、缶トマト、ソース類）は米国の一般的な市販品を想定する（What's Cooking は米国のレシピサイト由来）
- 香り（ハーブ・スパイスの本体）、脂のコク、渋み、清涼感、食感は 6 軸に入れない。入れられない分は `note` に書く

## 6 軸
| 列 | 軸 | 含めるもの |
|---|---|---|
| `sweet` | 甘 | 糖の甘み。アミノ酸（えび）の甘みも含む |
| `salty` | 塩 | 塩化ナトリウムの塩味 |
| `sour` | 酸 | 酢・柑橘・乳酸・トマトの酸味 |
| `bitter` | 苦 | 苦み。えぐみ（ほうれん草）とタンニンの渋み（赤ワイン）は苦に寄せた |
| `umami` | 旨 | グルタミン酸・イノシン酸などの旨み |
| `spicy` | 辛 | 唐辛子・胡椒・生姜・辛子・大根・生のねぎ類の刺激。アルコールの刺激とメントールの清涼感は含めない |

## 尺度（0〜5 の整数）
| 値 | 意味 | 例 |
|---|---|---|
| 0 | その味をほぼ感じない | 小麦粉の全軸、水 |
| 1 | かすかに感じる | 米の甘み、卵の旨み |
| 2 | はっきりあるが脇役 | 牛乳の甘み、にんじんの甘み |
| 3 | 目立つ。味の特徴のひとつ | サワークリームの酸味、ひき肉の旨み、生姜の辛み |
| 4 | 強い。味の中心に近い | 醤油の旨み、黒胡椒の辛み、みりんの甘み |
| 5 | その味が主役 | 砂糖の甘、塩の塩、レモン汁の酸、魚醤の塩と旨、カイエンの辛 |

- 軸どうしは独立に採点する（合計の制約はない）。魚醤は塩 5・旨 5
- 苦は 0〜3 しか使っていない（300 食材に苦みが主役のものが無いため。無糖ココア（unsweetened cocoa powder）は 308 位で対象外）

## `confidence`
- `high`: 誰が付けても ±1 に収まると思うもの（塩、砂糖、水、酢）
- `medium`: 品種・製品・加熱の有無で ±1〜2 動くもの
- `low`: 名前だけでは何を指すか決まらない（`sauce`、`juice`、`pepper`）、または生と加熱で大きく変わるのに通常の形が決めきれないもの（にんにく）

## `canonical`
- 表記揺れ・加工違いを束ねる代表名（`low sodium soy sauce` → `soy sauce`、`garlic cloves` → `garlic`）
- 行は統合せずに残す。同じ `canonical` でもスコアは違ってよい（有塩 `butter` と `unsalted butter`、`dark soy sauce`）

## 対象食材の選定
- `data/processed/whats_cooking_tokens.tsv`（Exp-01 の正規化済み食材。NFKC・小文字化・®/™除去・空白畳み込みのみで、表記揺れは統合していない）
- 食材を含むレシピ数（1 レシピ内の重複は 1 回）の多い順。300 位の件数（268）以上をすべて採った → **303 食材**（ユニーク 6,703 種中）。268 件の同数が 299〜303 位にまたがるため
- 再現・検査: `uv run python experiments/exp-02/select_ingredients.py --check`
