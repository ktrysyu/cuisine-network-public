# Exp-19 酢とポーチドエッグ: 酢の代わりに同じ量の水・多めの差し水を足したら

（Claude の記録。実装・実行の前に書いてコミットした）

## きっかけ（本人 2026-09-30）
通説「ポーチドエッグは、湯に酢を入れるとまとまる」に対照を足す。本人の仮説: 「酢の性質（酸）ではなく、あとから何かを足すこと（差し湯・差し水）に意味があるのでは」。

## 比べる4条件
1 L の沸騰した湯（100℃）に、20℃の液を足してすぐ卵（60 g、20℃）を落とす。

| 条件 | 足すもの | 量 |
|---|---|---|
| ① | 何も足さない | 0 |
| ② | 酢 | 湯量の 3%・4.5%（30 mL・45 mL。R-E22 の例: ワインビネガー 3%、穀物酢・米酢 4.5%） |
| ③ | 水 | ② と同じ量（30 mL・45 mL） |
| ④ | 多めの差し水 | 100・150・200 mL と、湯が 85℃ になる量（熱収支から逆算） |

## 計算
1. **足した直後の湯温（熱収支）**: 湯と足した液が一様に混ざるとして
   T = (m_w c_w(100℃)·100 + m_a c_a(20℃)·20 + C_pot·100) / (m_w c_w + m_a c_a + C_pot)
   - 湯 1 L の質量は 100℃の密度から 958.35 g、足す液は 20℃の密度 998.21 kg/m³ で体積から質量に（Engineering ToolBox の水の密度の表）
   - 比熱: 水 100℃ 4.2157、20℃ 4.1844 kJ/(kg·K)（Engineering ToolBox の水の比熱の表）
   - **酢は水と同じとみなす（近似）**。差の見積もり: 酢酸 4.2%（穀物酢の酸度の例）を質量で重み付けすると c = 0.958×4.1844 + 0.042×2.050 = 4.10 kJ/(kg·K)（酢酸の液体 123.1 J/(mol·K)、NIST Chemistry WebBook、Martin & Andon 1982、分子量 60.05）。密度の差（酢 約 1.01）も含め、混ぜた後の湯温の差を出す
   - 鍋の熱容量は主の計算では入れない（C_pot = 0）。感度として 500 J/K（ステンレス 1 kg 程度、仮定）
2. **沸騰が止まる時間（再沸騰までの時間）**: 足した後、コンロの正味の加熱量 P がすべて湯を温める（100℃ 未満では蒸発・放熱を無視）として、湯と卵の熱の出入りを 1 秒刻みで進め、湯が 100℃ に戻るまでの時間。
   - **火力 P は仮定**: 湯に入る正味の熱量 1.0・1.5・2.0 kW（出典なし。家庭のコンロの幅を想定した値）
   - 100℃ 未満での蒸発・放熱を無視するので、再沸騰までの時間は短めに出る（下限）
   - 卵が湯から奪う熱も入れる（卵の熱伝導の計算から、毎刻みの卵の熱量の増え方）
3. **白身の固まる速さ**: Exp-17 の卵の計算（experiments/exp-14/sim/egg_kinetic.py、2層の球の熱伝導＋場所ごとの変性の一次反応）を、表面＝上の湯温の履歴で解く。
   - 割った卵を同じ質量の球とみなす（実際の割った卵は平たく広がり、表面が大きい。球は固まり方を遅めに出す側）
   - 表面の数 mm の固まり方を見たいので、半径方向 240 節点（約 0.1 mm）、0.5 秒刻み
   - 出す値: 表面から X ≥ 0.9 の厚さ（5・10・30・60 秒）、外側 1 mm が固まるまでの時間、白身の体積の半分・9割が固まるまでの時間、4 分後の黄身の平均の変性度
   - 感度: 表面の条件を 表面＝湯温 の代わりに熱伝達率 h = 800 W/(m²·K)（rules.yaml egg_sphere.Bi_air の注記にある湯の例題の値）のロバン条件
4. **酸による凝固の促進**: 計算に入れない。出典は向き（速まる）だけで、何分・何℃ 速まるかの数値が無い（R-E22 確かさ 中、R-E23 は pH ごとの変性温度の数値が抄録に無い、R-E14 未確認）。② と ③ は計算の上では同じ反応の速さで解き、違いは「酸の分（数値なし）」として書く
5. **湯の動き（対流）**: 今の計算は湯の動きを持たないので、② と ③、① と ④ の違いのうち湯の動きの部分は区別できない。出典（R-E21: 沸騰では対流で卵白がちぎれる、80〜85℃ で沸騰させない）と、上の再沸騰までの時間から推定として分けて書く

## 判定の約束（結果を見る前に決めた）
- ② と ③ の湯温の履歴の差が 0.2℃ 以内、白身の固まる時間の差が 1 秒以内なら「計算の上で酢は同じ量の水と同じ」とする
- 「足すこと」の効き目を支持する: 足した液（と卵）で沸騰が止まる時間が、白身の外側 1 mm が固まるまでの時間より長いこと（泡が立たない間に表面が固まる）
- 支持しない: 沸騰が止まる時間が外側 1 mm の固まる時間より短い（固まる前に沸騰が戻る）
- どちらの場合も、湯の動きがまとまりを決めるかは出典（R-E21、確かさ 低）の範囲の推定で、計算では確かめていない

## 正直に書いておくこと
- 卵は球で、割った卵の広がりを入れていない。変性の式（Di Lorenzo et al. 2025）は殻付き卵の論文の値で、酸を含まない
- 湯の中の温度むら（足した液の周り・卵の周りが冷たい）は入れていない。一様に混ざるとした
- 火力・鍋の熱容量は仮定

## 結果（2026-09-30、実行後に書いた。Claude の記録）
表は `results/output.md`（run.py が生成）。火力は仮定の 1.5 kW を主に、1.0・2.0 kW を並べた。

- **足した直後の湯温**: ① 100℃、② 酢 3%（30 mL）97.6℃・4.5%（45 mL）96.4℃、③ 同じ量の水も 97.6℃・96.4℃、④ 差し水 100 mL 92.5℃・150 mL 89.3℃・200 mL 86.3℃、223 mL で 85.0℃
- **② と ③ の差**: 酢を水と同じとみなした主の計算では同じ。酢の物性（c 4.10 kJ/(kg·K)・ρ 1.01）で計算しても直後の湯温の差は 0.03〜0.04℃、白身・沸騰の時間の差は 0 秒。判定の約束（0.2℃・1 秒以内）で「計算の上で酢は同じ量の水と同じ」
- **沸騰が止まる時間（再沸騰までの下限）**: ② ③ 6〜19 秒、④ 100 mL 19〜39 秒・200 mL 36〜74 秒・223 mL 40〜82 秒（2.0〜1.0 kW）。① は卵を入れても湯温は 100℃ のまま（卵が毎秒奪う熱は火力より小さい）
- **白身の固まり方**: 湯温が 85℃ 以上なら、湯にふれた表面は 5 秒以内に固まる（X=0.9 まで 100℃ 0.02 秒・90℃ 0.7 秒・85℃ 5 秒）。そこから内側へは熱が伝わる速さで決まり、外側 1 mm が固まるのは ①〜③ 38.5〜39 秒、④ 100 mL 40.5 秒・200 mL 50.5 秒・223 mL 53.5 秒。白身の半分は 148〜154 秒で、条件の差は小さい
- **判定の約束**: ② ③ は沸騰が戻る（6〜19 秒）のが外側 1 mm が固まる（約 39 秒）より早く、**酢の量の「足すこと」の効き目は支持しない**。④ は 200 mL 以上で、火力 1.0 kW なら沸騰が止まる時間の方が長く、1.5 kW でほぼ同じ、2.0 kW では短い。**多めの差し水は火力しだいで境目**
- 感度: 鍋 500 J/K を入れると直後の湯温は 0.3〜1.4℃ 高く、時間はほぼ同じ。表面を h=800 のロバン条件にすると外側 1 mm は 82〜90 秒に延び（表面が湯温に追いつくのに時間がかかる）、④ 223 mL でも 1.0 kW の 82 秒と同じくらい。格子 120・240・480 節点で外側 1 mm の時間の差は 4 秒以内
- 酸の効き目は計算に入れていない（数値の出典が無い）。② と ③ の違いが出るなら、それは酸（または計算に無いもの）の分
- 湯の動きは計算に無い。出典（R-E21）の「沸騰では対流で卵白がちぎれる」を当てはめると、足した液で泡が止まるのは ② ③ で 6〜19 秒。それより後は沸騰した湯の中で固まる途中の白身が動く、という推定になる
