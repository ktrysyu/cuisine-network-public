# Exp-09 埋め込み空間の答えと Jev の分布を比べる

問い: Q6 を「本人の目視」ではなく分布で評価する。あわせて、LLM が持つ料理の常識と、実レシピの共起から学習した空間がどこでずれるかを見る。

## 位置づけ
Jev（TypeSafe AI）の答えも LLM の知識から出るので正解ではない。「LLM の料理の常識」という比較相手として使う。学習データには使わない。

## 手順
1. Exp-01（と Exp-01b）の足し引きの式ごとに、Jev の Choice で「X の Y 料理版は？」を聞く
   - 選択肢 = 空間の上位 k 件 ∪ 一般的に考えられる答え（本人が数個足す）∪ 無関係な対照 2〜3 件
   - criteria の説明文は食材名だけにして、説明文で答えを誘導しない。選択肢の順番はシャッフルし、並べ替えて2回聞いて安定性も見る
2. 返ってきた確率分布・Confidence を記録する
3. 比べる
   - 空間の1位が Jev の分布で何%もらえるか
   - 空間の順位と Jev の確率の順位相関
   - Confidence が高い（Jev が迷わない）のに空間が外している問い = 空間側の問題の候補

## API
- エンドポイント: POST https://api.typesafe.ai/v1/systemone（Python SDK `typesafe-sdk`）
- 認証: 環境変数 `TYPESAFE_API_KEY`。キーはリポジトリ直下の `.env` に置く（gitignore 済み）
- Choice の選択肢は最大 255 個
- 料金・レート制限はドキュメントに記載なし（2026-09-27 確認）。429 のとき `retry_after_ms` が返る。1 呼び出しで複数の質問をまとめて送れるので、式ごとではなくまとめて送って呼び出し回数を抑える
- 生のリクエストとレスポンスは `experiments/exp-09/results/raw/` に全部保存する（再実行せずに再集計できるように）
