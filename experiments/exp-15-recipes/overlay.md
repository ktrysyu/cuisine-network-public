# Exp-15 世の中のレシピを Exp-14 の地図に重ねる

`overlay.py` が生成（手で直さない）。2026-09-28。`recipes.csv` の `map_ok=yes` の 28 行を、卵の形に合う Exp-14 の地図（`experiments/exp-14/sim/maps.py` の PRESETS）に点として置き、**その点ちょうど**の計算の答え（判定の1位）とレシピの料理を比べた。

- 計算・レシピの値は合わせ込んでいない。判定は Exp-14 のまま（必須条件＋下限 0.6）。点の温度は `map_T_c`（原文の数値の中央、無ければ換算表の推定の中心）、時間は `map_time_min`
- 「参考」の列（推定・時間の幅の端での答え、手順を変えた場合の答え）は理由の候補を確かめるためだけに出した。一致・不一致の集計には使っていない
- 殻付き卵は後の手順（`recipes.csv` の `after_step`、`techniques` から機械的に読んだ）で地図を選ぶ: 氷水・冷水・流水に取る行は「氷水に取る」の地図（冷水・流水は後の手順の水温を 15℃にして計算）、書いていない行は「室温に置く」の地図（Exp-14 rules.md §10 2026-09-28 夜「余熱」）。参考の列に、逆の後の手順（すぐ氷水／室温に置く）での答えを出した
- 図: `figures/overlay.png`（地図6枚。塗りは Exp-14 の地図と同じ、点の形・色は料理、中抜きは温度が推定、塗りつぶしは原文に数値）。ページ: `writeup/cook-lab.html` の地図で「世の中のレシピを重ねる」

## 4. 一致したが中身に注意がある点

- R027（ポーチドエッグ、100℃・2分）: 沸騰した湯。地図の元は酢なしで「ばらける」。レシピどおり酢を入れると「まとまる（表面に膜・ちぎれ）」（R-E22）
- R053（プリン、100℃・35分）: 100℃で蒸すと す が立つ（porosity）が、す は必須条件ではないのでプリンと答える（maps.md §6）
