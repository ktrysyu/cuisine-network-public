# Exp-01b 追加: 方向の求め方の比較（主要指標）

- 方法の定義は run_methods.py の docstring と run_log.md。k = 取り除いた本数。k=0 は Exp-01 そのままの空間
- 指標は run.py と同じ関数で計算（10-NN 国籍一致率、シルエット、除去後に LDA を学習し直した 5-fold 精度、製菓レシピの 10-NN 製菓一致率、食材ベクトルから取り除いた二乗ノルムの割合）
- 「重心差の割合」= cuisine 重心 − 全体平均 の 20×100 行列の二乗ノルムのうち、除去した部分空間に入る割合。「料理分散の割合」= k=0 の料理ベクトルの全分散のうち、除去した部分空間に入る割合
- 和食最近傍 K+C = japanese レシピの「他 cuisine 最近傍」が korean か chinese である割合
- 醤油↔バター ρ = soy sauce↔butter 軸の cuisine 平均の並びの k=0 との順位相関。η² = その軸の射影値の分散のうち cuisine で説明される割合
