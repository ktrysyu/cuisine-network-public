# Exp-14 結果: 調理のシミュレータ（状態の計算と料理の判定）

2026-09-27（2026-09-28 更新）。再現: `uv run pytest experiments/exp-14`（91 passed / 3 xfailed、2026-09-28 修正 B の後）、`uv run python experiments/exp-14/run.py`（表は [`run_output.md`](run_output.md)、値は `run_output.json`）。

## 何を作ったか

- `sim/state.py`: 食材の質量と成分表から組成（水分・脂質・糖・塩 …）を計算する。中心・表面の温度と、温度履歴（温度帯ごとの保持時間）を持つ
- `sim/ops.py`: 操作（混ぜる・撹拌・こねる・浸す・加熱・焼く・蒸す・煮る・揚げる・冷やす・寝かせる・発酵）を State→State の純粋な関数にした。加熱系はすべて `heat(媒体, 温度, 時間, 撹拌, 蓋)` の特殊化。**加熱は時間の代わりに停止条件（`until`）でも止められる**（下の「今回の変更」）
- `sim/physics.py`: 規則。**すべて「到達温度のしきい値」か「ある温度帯にいた時間の合計」**で段階を進める。反応速度論は使っていない
- `sim/judge.py`: 料理を条件の組み合わせ（範囲・段階・真偽・保持時間）で持ち、満たした割合（重み付けなし）で順位を付ける。**必須条件（食材・殻付き）を満たさない料理は候補から外し、1位の割合が下限未満なら「該当なし」を返す**。距離関数は使わない。答えと一緒に、上位の候補・満たした条件・満たさなかった条件と実際の値を返す
- 採用値は `rules.yaml` の `sim`、料理の条件は `dish_conditions`（変更履歴は rules.md §10）

## 6. 設計上の迷いどころ（前回からの更新）

1. **時間で指定するレシピと「〜になるまで」のレシピ**: until を足した。家庭の合図で止めると、卵・カラメル・プリン・牛乳ゼリーは探索なしで通る。一方で、止めるまでの速さがモデルの時定数（推定）そのものになるので、炒め玉ねぎ（表面の乾き）と鶏むね肉（中心の温まり）で推定値のずれが表に出た。時間の版では、時間を窓に合わせることでこのずれが隠れていた
2. **停止の合図が片面ごと・部位ごとの場合**: パンケーキの「両面に焼き色」は State が表面を1つしか持たないので書けない
3. **割合は条件の数に引っ張られる**: 殻付きの必須化で「ゆで卵が1位」は消えたが、す立ちのプリン液はプリン自身の 6/9 で残った。条件が9つの料理は3つ外しても 0.67
4. **下限 0.6 で分かれたのは 0.50〜0.56 と 0.67 の間**: 今回の入力で割合が 0.6〜0.7 に入ったのは 100℃プリン（0.67）とゼラチン（0.67）の2件で、どちらも「答えの集合に無い状態」。下限を上げるか、答えの集合に「失敗した料理」を足すか、条件に重みを付けるかは未決
5. **組のレシピ**: 順番を変えた7組は時間の版のまま。停止条件で書き直すと、撹拌の有無の組は止める条件も変わる（スクランブルエッグ ≧2、オムレツ ≧1）ので、「撹拌だけ変える」組として成り立たなくなる
6. **薄め方による凝固温度（C3）**: 変わらず残る。代替値 85℃ で時間の版が外れなくなったのは、ゆで卵が候補から外れたためで、凝固の扱いが良くなったわけではない

**残った問題（直していない）**
- 殻付き卵以外（割った卵・溶き卵・器の卵液・肉 など）は1つの温度の一次遅れで、余熱を表せない（中心が周りの温度を越えない）。ポーチドエッグ・プリン・茶碗蒸し・鶏むね肉のソテーの余熱は入っていない
- 「書いていない＝室温に置く」で、世の中の半熟ゆで卵のレシピ 3 行が該当なしになった。実際にどれくらいの時間で食べるか・殻をむくかは分からない。置く時間を短くする（食べるまで 1〜2分）根拠の出典は探していない
- 空気の表面の条件（Bi_air）は出典の範囲から置いた推定。濡れた殻からの蒸発（取り出した直後は表面が冷えやすい）は入れていない
- 冷水・氷水も「表面＝水の温度」（Bi→∞）。静かな冷水の自然対流では表面が少し遅れて冷え、余熱は計算より少し大きい
- 湯に入れたまま火を止める（off_heat）の湯の冷え方（時定数 90分）は出典のない推定で、重ね合わせには使っていない（Exp-15 の 5 行は map_ok=no のまま）
- 地図（室温に置く）で、80〜85℃の 7〜9分が温泉卵になった（卵白の層が 80℃に届かず卵白 2、中心は 65〜70℃）。氷水の地図でも 80〜82.5℃の 11〜13分。短い時間で湯から出した卵を温泉卵と呼ぶかは決めていない
