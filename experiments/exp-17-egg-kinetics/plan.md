# Exp-17 殻付き卵を熱伝導と変性の速さで解く

（Claude の記録。実装・実行の前に書いてコミットした）

## きっかけ（本人 2026-09-29〜30）
殻付き卵の白身の固まり方を「平均温度で決める／表面温度で決める」と人が選ぶのをやめる。本人: 「これは決めるものじゃない。自然に従うように、できるだけ頑張って近づけて」。

## 今の形（Exp-14、変える前）
- 温度: 一様な球の熱伝導の解（固有関数の展開）。R²/α = 60.5分は温泉卵の論文（tatsu2019）の1点に合わせた値。白身の層は体積平均の温度1つ
- 固まり方: 白身は白身の層の最高温度、黄身は中心の最高温度を、しきい値（白身 60/65/80℃、黄身 65/70/80℃）で段階に変える。時間は効かない（温泉卵の「65℃以上で3分」だけ保持時間）

## 新しい形
1. **温度**: 卵を黄身（中心の球）と白身（外側の殻状の層）の2層の球とし、1次元・球対称の熱伝導を差分で解く（陰解法、半径方向 60 節点）。各層の熱伝導率・密度は温度の関数、比熱は定数（Di Lorenzo et al. 2025 Table 4、元は Abbasnezhad et al. 2016）
   - 黄身 k = 0.0008T + 0.395 W/(m·K)、ρ = −0.0023T² − 0.1386T + 1037.3 kg/m³、cp = 3120 J/(kg·K)
   - 白身 k = 0.0013T + 0.5125、ρ = −0.0041T² − 0.0115T + 1043.3、cp = 3800（T は ℃）
   - 大きさは中身の質量から: 半径 R = (3m / 4πρ)^(1/3)（ρ は 20℃の体積で重み付け）。黄身は体積の 34%（egg_structure、Exp-14 と同じ）。**R²/α を実測に合わせる操作はやめる**（tatsu2019 は照合に回す）
   - 殻は入れない（Di Lorenzo et al. も入れていない。殻 0.2〜0.38mm）。気室・対流・水分移動も入れない（同）
   - 表面: 湯・蒸気・水は 表面＝媒体温度（Exp-14 と同じ）。空気は熱伝達率 h（Exp-14 の Bi_air 0.5 と同じ h = 10 W/(m²·K)、wiki_htc）のロバン条件
2. **変性**: 場所ごとの変性度 X（0〜1）を一次反応で積分する（同 Table 4）
   - dX/dt = A·exp(−Ea/RT)·(1 − X)
   - 黄身 A = 2.72×10⁵⁰ s⁻¹、Ea = 3.443×10⁵ J/mol。白身 A = 4.85×10⁶⁰ s⁻¹、Ea = 4.185×10⁵ J/mol
3. **固まり具合（段階）**: 場所ごとの X の分布から出す。**結果を見る前に決めた（仮）**
   - その層の体積のうち X ≥ 0.9（9割変性）の割合を g、体積平均を X̄ とする
   - 段階1（とろみ・白濁）: X̄ ≥ 0.1 ／ 段階2: g ≥ 0.5 ／ 段階3: g ≥ 0.9
   - 黄身の段階3（ほろほろ）は g ≥ 0.9 に加えて中心の最高温度 ≥ 80℃（Exp-14 の R-E06 をそのまま残す。変性度の式からは出ない性質のため）
   - 感度として事前に決める代わりの値: 固まったとみなす X を 0.5・0.99、段階2の g を 0.3・0.7
4. 殻付き卵以外（溶き卵・割った卵・プリン液など）は変えない
5. 実装は `experiments/exp-14/sim/egg_kinetic.py`。rules.yaml に `egg_model: stage | kinetic` を足し、**既定は stage（今の形）のまま**にして両方を並べて評価する。試せるページ（JavaScript 版）はまだ移さない。既定を切り替えるかは評価を見て本人と決める

## 評価（結果を見る前に決めた）
1. **実装の確かめ**: Di Lorenzo et al. 2025 の条件（楕円 7×5cm と同じ体積の球、黄身の半径 1.5cm、20℃から）で、本文の記述と合うか
   - 100℃ 12分: 白身・黄身とも X が 1 に達する
   - 100℃ 6分: 白身は X=1、黄身は中心で 0.5 前後まで下がる
   - 65℃ 1時間: 黄身は X=1、白身は 1 に達しない
2. **既知の実測との照合（出典つき）**
   - tatsu2019: 20℃の卵を 68℃の湯に入れて、中心が湯温の 1℃以内に達するのが約28分
   - 世の中のレシピ（Exp-15 の重ね合わせ、28点）: 半熟ゆで卵（沸騰 4〜7分）・固ゆで卵・温泉卵の一致数
3. **既存の答えが変わらないか**: 正解のレシピ（状態で止める版・時間の版）と順番を変えた7組の答え
4. **地図の変化**: 殻付き卵の地図2枚（室温に置く・氷水に取る）のマスの変化
5. 感度: 上の代わりの値

## 正直に書いておくこと
- 変性度 X は「どれだけ固まったか」の物理量として論文が使っている量で、見た目（流れる・とろとろ）との対応は論文の官能評価の記述（半熟の黄身は X が 0.5 まで下がってもとろとろ）以上には分からない。段階への変換（X ≥ 0.9 など）は仮
- 白身・黄身とも、たんぱく質の種類ごと（オボトランスフェリン 61℃・オボアルブミン 84℃など）ではなく、層ごと1本の反応でまとめた（論文と同じ）
- A が 10⁶⁰ のような値は、Ea と組みで意味を持つ当てはめの値。温度の範囲の外（〜60℃未満・100℃超）では外挿

## 結果（2026-09-30、実行後に書いた。Claude の記録）
表は `results/output.md`（run.py が生成）。

- **tatsu2019 と合わせ込みなしで一致**: 20℃の卵を 68℃の湯に入れて中心が 67℃に達するのは 28.4分（論文 約28分）。Exp-14 はこの1点に R²/α を合わせていたが、今回は熱物性（Di Lorenzo et al. Table 4）と卵の質量だけから出た（R²/α = 70.4分）
- 格子 60 と 120 節点で結果はほぼ同じ（黄身の固まった割合の差 0.03 以内）
- **Di Lorenzo et al. の本文の記述は再現できなかった**: 論文は「100℃ 12分で全体が 100℃」とするが、同じ Table 4 の値で計算すると中心は 61℃（彼らの卵の大きさ）。論文は熱拡散率を O(10⁻⁵) m²/s と書いているが、Table 4 の k/(ρ·cp) は約 1.3×10⁻⁷ m²/s で、100倍ずれている。本文の記述はこの食い違いの影響かもしれない（確かめられない）。反応の速さの式（A・Ea）はそのまま使った
- **正解のレシピ（両版）と順番を変えた7組: 答えが変わったのは 0/46**。段階は動いた（温泉卵 白身 2→1・黄身 1→2、半熟ゆで卵 黄身 0→1）
- **沸騰した湯 → 氷水**: 半熟ゆで卵になるのは 6〜6.5分（stage は 3〜7分）。3〜5分は白身が固まりきらず該当なし、7〜10分は黄身が半分以上固まって該当なし、11分から固ゆで。**白身は外側から固まっていき（1分 22%・3分 59%・5分 88%・6分 100%）、どこで固まったかを人が決めなくても出る**
- **68℃の湯 → 氷水**: 温泉卵は 25分から（stage は 20分から）。白身は 60分でも固まった割合 0（平均の変性度 0.68）、黄身は 30分でほぼ全体が固まる
- 殻付き卵の地図: 630マス中 63（室温に置く）・65（氷水）が変わった。多くは「生のまま ↔ 該当なし」（白身が少しでも変性したかの境目）
- 世の中のレシピ 28点: 22 → 21（半熟ゆで卵 R006「沸騰7分→氷水」が該当なしになった）
- 感度: 固まったとみなす変性度を 0.99 にすると 22/28 に戻り、0.5 にすると半熟ゆで卵の正解のレシピも外れる（20/28）。段階の決め方（仮）が半熟の境目を左右する
- 既定（rules.yaml `egg_model`）は stage のまま。試せるページ（JavaScript）は未移植

## 既定の切り替え（2026-09-30 本人決定。2026-10-22 に記録）
- rules.yaml `sim.egg_model` を kinetic に。試せるページ（JavaScript）も同じ値を使う。stage の計算そのものを確かめるテストは `experiments/exp-14/conftest.py` の `stage_model` で固定
- 変わった答え: 世の中のレシピ 22/28 → 21/28（R006 のみ）。R002 は参考の「すぐ氷水に取った場合」だけが 半熟ゆで卵 → 該当なし。Exp-14 の時間を一律に変えた表で半熟ゆで卵の ×1.1・×1.2 が該当なし
- 原因: 段階の決め方（仮）。長い側は黄身の g ≥ 0.5 で卵黄 2（沸騰 7分→氷水で g = 0.56、湯から出した時点 0.37、境目は 6.8分）。短い側は白身の g < 0.9 で卵白 2（沸騰 5分→氷水で 0.88）。氷水に取る処理は原因ではない（中心の最高温度は stage 65.7℃・kinetic 64.5℃ でほぼ同じ）
- 直していない: 境目（gel_X・stage2_g）にも半熟ゆで卵の条件にも出典の裏づけが無く（threshold_sources.md）、結果を見てから動かすと合わせ込みになるため
